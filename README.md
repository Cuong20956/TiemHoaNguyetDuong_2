# TIỆM HOA NGUYỆT ĐƯỜNG

Website quản lý cửa hàng hoa và đặt hoa theo sự kiện.

## Công nghệ

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Chức năng

- Dashboard quản lý
- Quản lý đơn hàng
- Thêm đơn
- Sửa đơn
- Xóa đơn
- Cập nhật trạng thái giao hàng
- Tìm kiếm đơn
- Sắp xếp đơn
- Quản lý tồn kho hoa
- Menu 20 loại hoa
- Tra cứu đơn hàng
- Thống kê doanh thu
- Thống kê hoa bán chạy
- Thống kê dịp đặt hoa phổ biến
